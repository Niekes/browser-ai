## The engine

Speech is turned into text by [Parakeet TDT 0.6B v3](https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3), a speech recognition model of NVIDIA, in the ONNX export of [`ysdede/parakeet-tdt-0.6b-v3-onnx`](https://huggingface.co/ysdede/parakeet-tdt-0.6b-v3-onnx), run by [parakeet.js](https://github.com/ysdede/parakeet.js) on onnxruntime-web. The encoder runs on the GPU through WebGPU, in 16-bit floats; the small decoder runs on the CPU. The model recognises 25 European languages and finds the language of a dictation by itself.

Everything runs in one Web Worker per page, which every input shares, so the page stays responsive and the model is in memory once. Only one input dictates at a time; the others wait.

## The model download

The model is about 1.3 GB. It downloads from Hugging Face only once the reader confirms it, pinned to one revision of the repository, and parakeet.js keeps it in the browser's IndexedDB. On the next visit it loads from there in a few seconds, without asking again. The WebAssembly files of the ONNX runtime come from the jsDelivr CDN. Audio never leaves the browser.

## A dictation

A click on the microphone starts a dictation, another click stops it, and Escape cancels it.

- **Live text.** While recording, the whole recording is transcribed again about every second, and the text shows at the cursor, provisional.
- **Final text.** On stop, a last pass over the whole recording replaces the live text with the final text, and the input's `onChange` receives the text with it at the cursor.
- **Long dictations.** Past a minute, the words that ended more than ten seconds before the end are frozen, and only the rest of the recording is transcribed again, so a pass stays short.

## The browser fallback

Where the engine cannot run - a phone, a tablet, a browser without WebGPU and 16-bit floats - the input says so and stays a plain textarea. With `browserFallback` turned on, it hands the dictation to the browser's own speech recognition instead, the [Web Speech API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API), if the browser has one. Wherever the engine runs, the engine is used.

The browser's recognition is not necessarily local: Safari hands the audio to Apple's speech recognition, Chrome sends it to Google's servers, and Firefox has none. So the option is off by default, and while it is in use the input says so: "Dictation uses this browser's speech recognition: the audio may leave this device." There is no model download.

The dictation works as with the engine: live text while you speak, the final text at the cursor when you stop, Escape to cancel. The browser needs a language, which the engine finds by itself: it takes the page's `lang`, else the browser's language. The examples on this site turn the option on.

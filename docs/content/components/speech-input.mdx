## Usage

Click the microphone and speak; click it again to stop, or press Escape to cancel. The first click asks to download the model, once. The words show at the cursor while you speak, and the final text lands there when you stop: typing and speaking mix.

The input is controlled by `value` and `onChange`, which receives the new text, so it fits a state or a form. With react-hook-form:

```tsx
<FormField
  control={form.control}
  name="message"
  render={({ field }) => <SpeechInput value={field.value} onChange={field.onChange} />}
/>
```

Every other prop goes to the textarea. While a dictation runs, the textarea is read-only.

Where the model cannot run, the input says so and stays a plain textarea. `browserFallback` lets it dictate there with the browser's own speech recognition, and the input then says the audio may leave the device:

```tsx
<SpeechInput value={message} onChange={setMessage} browserFallback />
```

It is off by default, as the browser's recognition is not necessarily local: see [the browser fallback](/docs/how-it-works#the-browser-fallback).
